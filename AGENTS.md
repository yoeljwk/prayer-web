# Preserve Existing Code & UI

## Source of Truth

The CURRENT files on disk are always the source of truth.

The user frequently modifies AI-generated code manually.

Any difference between code previously generated by the agent and the
current codebase MUST be treated as an intentional user modification.

Before editing any file:

1. Re-read the current file from disk.
2. Understand the current implementation.
3. Modify only what is necessary for the requested task.
4. Preserve everything unrelated to the requested change.

## Never Revert User Changes

NEVER:

- Restore an older implementation.
- Revert manual user modifications.
- Replace current code with code from previous conversation context.
- Rewrite an entire component when a localized change is sufficient.
- Refactor unrelated code without explicit permission.
- Remove existing functionality unless explicitly requested.

If your previous implementation conflicts with the current filesystem:

CURRENT FILESYSTEM ALWAYS WINS.

## UI Preservation

Existing UI is LOCKED by default.

Unless explicitly requested, NEVER change:

- layout
- colors
- backgrounds
- spacing
- padding
- margins
- typography
- font sizes
- font weights
- border radius
- borders
- shadows
- dimensions
- positioning
- icons
- animations
- transitions
- responsive behavior
- breakpoints
- existing text
- component hierarchy

When adding new UI, adapt the NEW UI to the existing design.

DO NOT modify the existing design to accommodate the new UI.

## Minimal Changes

Always use the smallest possible change.

For example:

If the user asks:

"Add a Recent Prayers section below the hero."

Then:

- Add the new section.
- Do not rebuild the Hero.
- Do not modify Navbar.
- Do not modify existing sections.
- Do not change global styles.
- Do not reorganize existing components unless required.

## Manual Changes Are Intentional

Example:

The agent previously generated:

rounded-xl p-6 bg-white

The current code contains:

rounded-[24px] p-8 bg-[#F8F7F3]

Assume the user intentionally changed it.

NEVER change it back to:

rounded-xl p-6 bg-white

unless explicitly requested.

## Before Finishing

Before completing every coding task:

1. Review the changes/diff.
2. Verify that unrelated files were not modified.
3. Verify that existing UI was preserved.
4. Verify that manual user modifications were preserved.
5. Remove accidental unrelated changes.
